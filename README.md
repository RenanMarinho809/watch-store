## 🛒 E-commerce de Relogio 

✨ Uma aplicação de e-commerce **limpa** e **totalmente funcional**, construída com:  
- ⚛️ **Next.js 15**  
- 🟦 **TypeScript**  
- 🍃 **MongoDB**  
- 🎨 **Tailwind CSS**  

### 🚀 Funcionalidades:
- 🖥️ **Server Actions** para lógica de backend  
- 🔗 **Route Handlers** para requisições de API  
- 🗄️ **Integração com MongoDB**  
- 📱 **UI responsiva e estilizada**
